# T9–T14 浏览器验收

当前实现与自动测试已完成；本会话没有连接可用浏览器，因此下面项目留待真实浏览器审查。自动测试中的 DOM 边界模拟不会计算布局，也不能证明浏览器快捷键、屏幕阅读器或移动键盘行为正确。

## 打开页面

运行 `pnpm dev`，打开终端显示的地址（通常 `http://localhost:4321`）。开发服务已运行时刷新页面即可。

## 首页与布局

- [ ] 首页首先显示 ASCII Logo、博客身份、最近文章与时间。
- [ ] 最近文章按日期从新到旧排列，标题可点击，与侧栏打开相同文章。
- [ ] 浅色和深色下正文、Logo、代码、终端都可读。
- [ ] 在约 1280px 宽桌面打开终端，阅读区缩小，底部终端不覆盖正文。
- [ ] 在约 768px 和 390px 宽页面，导航与终端按钮可用，普通页面不出现横向溢出。
- [ ] 手机上打开输入法键盘，仍能看到命令输入框与执行按钮，正文末尾可以滚动到。

## 键盘、触屏和焦点

- [ ] 鼠标／触屏点击底部「终端」按钮可以打开和关闭。
- [ ] Ctrl + 反引号打开终端并聚焦输入框；重复按下可关闭。
- [ ] 输入框聚焦时 Esc 关闭终端，并返回之前的触发控件。
- [ ] Tab / Shift+Tab 能离开终端，没有焦点陷阱，焦点轮廓可见。
- [ ] 输入中文时，确认候选词不会提前执行命令，上下键不会抢占候选选择。
- [ ] 首页的 `help` 按钮填入 `help`，按回车执行后可阅读和滚动帮助输出。

## 命令与一致性

以下命令请**逐行执行**：

```text
help
pwd
ls
cd posts
pwd
ls
cat learning-backtracking.md
theme dark
theme
history
home
```

- [ ] `cat` 打开文章，同时保留终端、目录与历史，并聚焦输入框。
- [ ] `theme dark` 让侧栏主题选择变成深色；侧栏再选浅色后，终端执行 `theme` 显示 light。
- [ ] `home` 回到首页，`pwd` 显示 `~`。
- [ ] 执行 `open ~/projects`、`cat ~/posts`、`cd ~/about.md`、未知命令时有明确反馈，没有跳转到 404。
- [ ] `search 回溯` 提示搜索暂未开放。
- [ ] `clear` 清空输出；之后按上键仍可回看历史。
- [ ] 输入一段未提交文字，按上键查看历史，再按下键回到末尾能恢复这段文字。
- [ ] `ls; home` 被拒绝，不执行多条 shell 命令。

## 刷新、前进和后退

- [ ] 打开终端执行 `cd posts` 后点击侧栏 about，目录仍为 `~/posts`，历史保留。
- [ ] 通过终端和侧栏交替导航，然后使用浏览器后退／前进，页面和选中侧栏项对应正确。
- [ ] 通过普通链接导航不会强行聚焦终端；通过终端命令导航会聚焦输入框。
- [ ] 刷新保留终端开关、目录、输入草稿、历史；显式主题也保留。
- [ ] 控制台没有运行时错误，Network 中没有缺失脚本、字体或其他资源。

若出现异常，请记录：浏览器及版本、页面宽度、命令顺序、实际现象、预期结果，以及控制台报错文本。
